# 1. SCOPE BOUNDARY & INVARIANTS

> [!IMPORTANT]

All UI, client-rendered components, dashboards, and landing pages are built and deployed independently by the frontend engineering team. This document serves as the binding contract that the future frontend must implement to interact with PromptIQ.

### Non-Negotiable Core Invariants:
1. **Zero Price & No BYOK (₹0 Forever)**:
   - PromptIQ is 100% free for all users.
   - The frontend **MUST NEVER** display input fields requesting OpenAI, Anthropic, Gemini, Groq, or OpenRouter API keys.
   - The frontend **MUST NEVER** display billing, credit card entry, payment gateways, or pricing tiers.

   - PromptIQ is a centrally hosted cloud service. The frontend never assumes local Ollama, llama.cpp, or client-side WebGPU execution.
3. **Canonical Project Constitution & Shared Memory**:
   - All state is synchronized across Web, Telegram Bot, MCP, and CLI surfaces through versioned Project Constitutions and persistent Project Memory.

# 2. AUTHENTICATION & SESSION LIFECYCLE CONTRACT

PromptIQ enforces secure JWT bearer authentication with rotating refresh tokens and server-side cryptographic token blocklisting.

### 2.1 Token Specifications
- **Access Token**: Short-lived JWT (`jti` unique claim, signed with HS256, 15–60 min lifetime).
- **Refresh Token**: High-entropy cryptographically secure random token (persisted in database as SHA-256 hash, 7-day lifetime, rotated on every refresh).
- **Authorization Header**: `Authorization: Bearer <access_token>`
- **Correlation Header**: `X-Request-ID: <uuid>` (sent by client or generated by backend).

### 2.2 Auth Endpoints

#### `POST /api/v1/auth/register`
Creates user account and automatically provisions an isolated personal workspace.
- **Request Body**:
  ```json
  {
    "email": "developer@example.com",
    "password": "StrongPassword123!",
    "full_name": "Ada Lovelace"
  }
  ```
- **Response** (`201 Created`):
  ```json
  {
    "access_token": "eyJhbGciOi...",
    "refresh_token": "rt_8f12a...",
    "token_type": "bearer",
    "user": {
      "id": "usr_9c8b...",
      "email": "developer@example.com",
      "full_name": "Ada Lovelace",
      "is_active": true
    }
  }
  ```

#### `POST /api/v1/auth/login`
Authenticates existing credentials and issues fresh access and refresh tokens.
- **Request Body**:
  ```json
  {
    "email": "developer@example.com",
    "password": "StrongPassword123!"
  }
  ```
- **Response** (`200 OK`): Same schema as register.

#### `POST /api/v1/auth/refresh`
Rotates the session. The provided refresh token is immediately revoked, and a fresh access token and new refresh token are returned. Replaying a used refresh token triggers security revocation of all active sessions.
- **Request Body**:
  ```json
  {
    "refresh_token": "rt_8f12a..."
  }
  ```
- **Response** (`200 OK`):
  ```json
  {
    "access_token": "eyJhbGciOi...",
    "refresh_token": "rt_fresh_4a...",
    "token_type": "bearer"
  }
  ```

#### `POST /api/v1/auth/logout`
Revokes the current access token by adding its hash to the server-side revocation table and invalidates active refresh tokens.
- **Headers**: `Authorization: Bearer <access_token>`
- **Response** (`200 OK`):
  ```json
  {
    "status": "success",
    "message": "Token revoked successfully"
  }
  ```

#### `POST /api/v1/auth/change-password`
Changes account password and invalidates all active sessions.
- **Request Body**:
  ```json
  {
    "current_password": "OldPassword123!",
    "new_password": "NewStrongPassword456!"
  }
  ```

#### `DELETE /api/v1/auth/me`
Permanently deletes user account, cascade-deleting workspace memberships and revoking sessions.

# 3. STANDARDIZED ERROR ENVELOPE

All non-2xx responses from PromptIQ follow a standardized JSON envelope.

```json
{
  "code": "CAPACITY_EXHAUSTED",
  "message": "All free model capacity for openai/gpt-oss-120b is temporarily saturated",
  "details": {
    "provider": "groq",
    "model_id": "openai/gpt-oss-120b",
    "retry_after_seconds": 26.5,
    "limit_type": "tpm"
  },
  "timestamp": "2026-11-22T06:30:00.000000Z",
  "request_id": "req_8f12ac78"
}
```

### Standard Status Codes:
- `400 Bad Request` (`VALIDATION_ERROR`): Malformed schema or invalid parameters.
- `401 Unauthorized` (`AUTHENTICATION_ERROR`): Missing, expired, or revoked token.
- `403 Forbidden` (`TENANT_ISOLATION_ERROR`): User attempting to access another tenant's project or artifact.
- `404 Not Found` (`NOT_FOUND`): Entity does not exist.
- `409 Conflict` (`CONFLICT_ERROR`): Concurrent edit or illegal state transition.
- `429 Too Many Requests` (`CAPACITY_EXHAUSTED`): Free tier quota window full. Header `Retry-After: <seconds>` is always present.
- `500 Internal Error` (`INTERNAL_ERROR`): Unexpected backend exception with sanitized error log.
- `503 Service Unavailable` (`PROVIDER_ERROR`): Upstream zero-price inference provider degraded.

# 4. DURABLE WORKFLOW & BACKGROUND JOBS API

Long-running operations (Prompt Compilation, Deep Research, Test Lab evaluations) execute as durable background jobs.

### 4.1 Job States
`QUEUED` → `RUNNING` → `PAUSED` (e.g. quota saturated) → `RESUMED` → `COMPLETED` / `COMPLETED_WITH_WARNINGS` / `FAILED` / `CANCELLED`

### 4.2 Job Endpoints

#### `POST /api/v1/jobs`
- **Request Body**:
  ```json
  {
    "operation_type": "PROMPT_COMPILATION",
    "project_id": "proj_123",
    "idempotency_key": "compile-v1-abc",
    "initial_stage": "task_discovery",
    "checkpoint_data": {"mode": "guided"}
  }
  ```
- **Response** (`201 Created`):
  ```json
  {
    "id": "job_456",
    "operation_type": "PROMPT_COMPILATION",
    "status": "QUEUED",
    "current_stage": "task_discovery",
    "progress_percent": 0,
    "stage_history": [
      {"stage": "task_discovery", "status": "QUEUED", "timestamp": "2026-11-22T06:30:00Z"}
    ],
    "execution_provenance": {},
    "checkpoint_data": {"mode": "guided"},
    "result_data": {},
    "created_at": "2026-11-22T06:30:00Z",
    "completed_at": null
  }
  ```

#### `GET /api/v1/jobs/{job_id}`
Retrieves job progress, current stage, and results. Polled by UI or subscribed via SSE.

#### `POST /api/v1/jobs/{job_id}/cancel`
Cancels in-progress execution with reason.

#### `POST /api/v1/jobs/{job_id}/resume`
Resumes execution from last saved checkpoint if job was paused due to quota exhaustion.

# 5. CORE PRODUCT SURFACE ROUTES

### 5.1 Projects & Constitution
- `GET /api/v1/projects`: List projects in user workspace.
- `POST /api/v1/projects`: Create project.
- `GET /api/v1/projects/{id}`: Get project details.
- `GET /api/v1/projects/{id}/constitution`: Get latest Project Constitution.
- `PUT /api/v1/projects/{id}/constitution`: Update requirements with strict provenance.
- `POST /api/v1/projects/{id}/constitution/approve`: Formally approve constitution version.

### 5.2 Adaptive Discovery
- `POST /api/v1/discovery/intake`: Submit project goal for Quick, Guided, or Deep intake.
- `POST /api/v1/discovery/answer`: Answer adaptive discovery questions (never re-asking confirmed items).

### 5.3 Prompt Autopsy & Adversarial Critique
- `POST /api/v1/critic/autopsy`: Analyze prompt for 21 defect categories. Returns verdict (`ready`, `ready_with_caveats`, `needs_revision`, `blocked`), findings with exact line citations, quality scores, and suggested revision.
- `POST /api/v1/critic/verify`: Deterministically verify whether revised text resolves prior autopsy findings.

### 5.4 Native Target Compiler
- `POST /api/v1/compiler/compile`: Compiles Project Constitution and Prompt Specification into target-native packages (Antigravity, Claude Code, OpenAI Codex, Cursor, Gemini CLI, etc.). Returns complete file tree and manifest.

### 5.5 Research & Evidence Ledger
- `POST /api/v1/research/execute`: Runs structured research with claim-evidence grounding, source deduplication, and contradiction analysis.

### 5.6 Test Lab
- `POST /api/v1/test-lab/evaluate`: Runs deterministic test suites against compiled packages with exact assertions.

# 6. CAPACITY TRANSPARENCY & UI GUIDELINES

When a `429 CAPACITY_EXHAUSTED` is returned:
1. Extract `details.retry_after_seconds` from error response or `Retry-After` HTTP header.
2. Render an in-place progress banner:
   *"All free model capacity is temporarily in use. Auto-resuming in {seconds}s..."*
3. Automatically resume or retry the request when countdown expires.
4. **Never** prompt the user to buy credits, enter billing details, or paste personal API keys.
