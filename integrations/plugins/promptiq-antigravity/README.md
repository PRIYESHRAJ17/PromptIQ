# PromptIQ Antigravity Native Plugin

Official PromptIQ intelligence and orchestration plugin for Google Antigravity.

## Features
- **Project Constitution Sync**: Access and propose changes to persistent architectural state.
- **Task Compiler**: Transform user intent into Antigravity instruction packages across 10 specialized task families.
- **Forensic Autopsy**: Dissect prompts against 18–21 adversarial failure categories before executing.
- **Evidence Graph**: Query citations with character-exact offsets.

## Installation into Antigravity

Antigravity loads plugins from global or workspace configuration directories:

1. **Global Installation**:
   Copy or link this folder into your global plugins directory:
   `~/.gemini/config/plugins/promptiq/`

2. **Workspace-Scoped Installation**:
   Copy or link this folder into your workspace directory:
   `.agents/plugins/promptiq/`

3. **Verify Installation**:
   Open Customizations in Antigravity or ask Antigravity to verify the `promptiq` plugin.
