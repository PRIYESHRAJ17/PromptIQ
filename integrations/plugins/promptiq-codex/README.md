# PromptIQ Codex Plugin

OpenAI Codex integration package. Provides schema validation, prompt compilation, and Project Constitution memory.

## Installation
From the repository root or extracted ZIP directory:
```bash
npm install -g ./integrations/plugins/promptiq-codex
```
Or directly from inside the plugin directory:
```bash
npm install -g .
```

Verify installation:
```bash
promptiq-codex
```
